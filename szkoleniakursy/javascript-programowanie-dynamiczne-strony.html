JavaScript - programowanie dynamicznych stron

Kogo zapraszamy?

Szkolenie przeznaczone jest dla osób znających podstawy HTML i CSS, które chcą rozszerzyć swoje umiejętności o programowanie w JavaScript.

Kurs przygotowuje do tworzenia dynamicznych i interaktywnych stron internetowych.

Termin, organizacja i metodyka szkolenia

Zajęcia realizowane są w trybie indywidualnym lub grupowym. Terminy ustalane są elastycznie.

Szkolenie prowadzone jest w formie praktycznych ćwiczeń komputerowych z naciskiem na tworzenie interaktywnych elementów stron WWW.

Kwalifikacje po ukończeniu szkolenia

Uczestnik otrzymuje certyfikat w języku polskim i angielskim. Możliwa jest wersja rozszerzona.

Ramowy program szkolenia

  • JavaScript w HTML
  • Zmienne i typy danych
  • Operacje matematyczne i logiczne
  • Instrukcje warunkowe
  • Pętle (for, while)
  • Funkcje
  • Tablice
  • DOM - Document Object Model
  • Obsługa zdarzeń
  • Walidacja formularzy
  • Programowanie obiektowe
  • Wbudowane obiekty JS
  • Manipulacja elementami strony
  • Konkatenacja i operacje na stringach
  • Break i continue
  • Tworzenie interaktywnych stron WWW
